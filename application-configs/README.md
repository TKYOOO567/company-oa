# 业务设计配置

本目录保存 O2OA 应用的脱敏流程、表单、门户、查询和统计等可导出设计定义。目前尚无本公司业务应用的原生导出文件。

后续按 `<application>/<version>/` 管理，至少附带：来源系统与版本、应用标识、配置类型、依赖、导出时间、适用环境、校验和验证记录。平台原生的导出、导入格式及依赖处理方式以实际技术验证为准。

不混入真实业务记录、附件内容、员工个人资料、登录凭据或生产运行配置。`docs/migration/` 的 JSON 盘点样例不是本目录的原生平台定义。

配置发布、回退和在途流程使用的版本规则须验证；不能用文件名中的版本号代替运行平台的实际版本行为。

参见 [改造方案](../docs/architecture/02-o2oa-adaptation-plan.md) 与 [待确认事项](../docs/requirements/03-open-questions.md)。
