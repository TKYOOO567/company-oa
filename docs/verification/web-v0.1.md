# Web v0.1 实现与验证

日期：2026-10-24，Asia/Shanghai。按用户要求先做模块化 Web 第一版，并完成 Java 环境、源码 O2OA、独立 MariaDB 与新 Web 的真实联调。

## 本版实现

Vue 3、TypeScript、Vite 独立工程包含平台连接、账号登录与退出、工作台、当前用户待办／已办、服务器搜索和分页、只读工作摘要与原生表单入口。页面、组件、状态、HTTP、平台适配器及演示适配器分别维护；默认连接真实平台，人工演示需主动进入。

本轮修复真实联调发现的退出问题：成功退出后重新检测平台及认证策略，支持直接登录另一账号，同时保留失败退出和旧请求竞态保护。平台必要变更限于外部数据库读取／启用／JNDI 注册、本机 HTTP 绑定，以及指定 utf8mb4 普通索引的兼容字典，已登记 [PATCH-0001](../../patches/o2oa/0001-external-database-and-local-binding.md)、[PATCH-0002](../../patches/o2oa/0002-mariadb-utf8mb4-index.md)。

运行说明见 [Web README](../../apps/oa-web/README.md)、[隔离环境工具](../../deployment/dev/README.md)，源码构建、数据库与限制详见[平台运行报告](platform-runtime.md)。

真实测试使用本项目独立库中的合成组织、普通账号和两个人工节点，不使用原纷享销客数据或已有业务库。正常账号待办归属检查只覆盖该场景；发起人可能有权读取相关工作摘要，不将它误判为越权。

`npm run test:e2e:live` 需显式启用及 `.local/live-integration.json`。默认待办阶段必须有已知真实待办；流程结束后使用 `OA_LIVE_STAGE=completed` 复查已办。真实测试不拦截请求、不进入演示，禁用截图、trace 和视频以减少凭据留存。最初界面演示截图 `.local/verification/web-v0.1/dashboard.png` 仅为人工示例，不能作为实际平台证据。
