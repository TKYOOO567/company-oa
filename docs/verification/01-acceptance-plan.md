## 8. 拟议通过规则与输出

以下为设计建议，需在正式执行前由验收负责人确认：

1. 纳入上线范围的需求都有配置或实现、测试及证据对应，不能用未实现或未执行项填充通过数量。
2. 跨公司越权、数据完整性或正式核算约束失败应先处理并复验；如有范围调整或例外，必须有明确业务决定，不能在报告中省略。
3. 迁移核对不存在未解释的数量、金额、关联差异；不可提取的历史资料及替代方式必须有处理结论。
4. 正式会计口径、期初/补账和总部报表有指定财务确认；登录、共享、在途切换和验收责任已落实。
5. 形成具名的验收结果、缺陷及差异清单、迁移对账材料、配置/源码版本、切换与恢复演练记录；通过后才能据 REQ-010 决定上线。
