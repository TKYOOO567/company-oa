# O2OA 后端适配与业务扩展

本目录用于后续必要的公司业务授权、校验、事务、平台接口适配及专项服务。目前没有新增 Java 模块、接口或可执行服务。

实施前先验证 Maven 父子模块、依赖、包名、实体管理、接口注册、构建输出和运行装配方式。目录本身不是平台自动发现的扩展入口；实际接入方式必须在技术验证后记录。

优先使用已有组织、流程、表单、查询和附件能力；平台配置不能可靠承担的服务端约束才通过扩展实现。不得把服务端授权放在前端过滤器里，也不得用本地假数据代替会计引擎。

参见 [目录规范](../../docs/architecture/01-repository-and-directories.md) 与 [扩展策略 ADR](../../docs/architecture/adr/0001-o2oa-extension-strategy.md)。
